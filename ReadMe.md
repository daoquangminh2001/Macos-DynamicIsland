# Atoll Local

Atoll dành cho Mac Apple Silicon: điều khiển nhanh ở vùng camera, nền kính và mèo pixel.

- **Cài đặt:** tải [bản DMG](https://github.com/daoquangminh2001/Macos-DynamicIsland/releases/latest), kéo app vào Applications. [Hướng dẫn ngắn](docs/INSTALL.vi.txt).
- **Giao diện:** Cài đặt → General → Hiệu ứng kính: **Tắt / Kính mềm / Semi Glass**.
- **Dựng từ source:** `ruby scripts/build-release.rb`. [Chi tiết](docs/BUILDING.vi.md).

Dựa trên [Atoll](https://github.com/Ebullioscopic/Atoll). [GPL v3](LICENSE); gửi kèm source ZIP khi chia sẻ app. Bản Local chặn kết nối IP.
